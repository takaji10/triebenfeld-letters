# Missing sources

The running list of what the edition cites and does not yet hold, for the
editor to bring in (the editor, 2026-10-23: "a running list of missing
sources, so that I know what still needs to be added to the project").

Two parts. **Cited by the gazetteer** is made by
`python pipeline/gazetteer/gazetteer.py --missing` from the footnotes of
`reference/gazetteer/` and from `reference/gazetteer_sources.yml` and
`reference/maps.yml`: run it after a source is brought in and the line goes.
**Elsewhere in the project** is kept by hand: the sources the plans and the
to-do list already wait on.

When a source comes in, set its key in `reference/gazetteer_sources.yml` to
resolve to it (or a map's `in_project: true` in `reference/maps.yml`), run the
script, and the footnotes that cite it become links.
