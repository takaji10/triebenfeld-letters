# Page forms in the transcriptions: a proposal

Drafted 2026-10-03 for the editor to rule on. Once ruled, the decisions go into
each holding's `transcription_decisions.csv` and this file is retired.

## The principle (editor, 2026-10-03)

- **Transcription and reading copy**: the name as the page writes it
  (Prussiemski, Zagorow, Franckfurth, Kriegs Rath).
- **English, summaries, register, index**: always the standard form
  (Prusimski, Zagórów, Frankfurt, Councillor of War).

The English is already written and is not re-translated, so putting a page form
back changes nothing in it; a later translation is held to the standard form by
the register and `english_forms.yml`. Each restored form is checked against the
register so that the name is still tagged.

## How the list was made

Every change to a transcription goes through a holding's
`transcription_decisions.csv`, so the earlier rulings that replaced a page
spelling with the edition's form can be traced back to what was first
transcribed. Each row below is a net change: first transcription → today's
transcription, with how many times it occurs.

Two kinds are mixed together in those rulings, and only the first should be
reversed:

- **standardised**: the page has a real spelling of the time, and it was
  replaced by the edition's form. *Proposed: put the page form back.*
- **misread**: the first transcription was wrong (Treibenfeld, Hohenlone,
  "le terre" for Lefebvre), and the ruling made it say what the page says.
  *Proposed: keep.*

Where I cannot tell which it is without the scan, the row says **check**.
