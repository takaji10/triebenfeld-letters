Include with kind="parchment" | "newspaper" | "book" | "map" and, optionally, variant="a" | "b" | "c" (2026-11-24; default c). Every parameter is read as include. - a bare `kind` is empty inside a Jekyll include (the 2026-11-07 bug that rendered empty SVGs). a the first line drawings, enlarged inside a tinted disc; b fuller line drawings inside a tinted rounded square; c the same drawings, duotone: a soft accent fill on the main shape (class "duo") beneath the line. All draw with currentColor and the site's tokens (--accent, --paper), so they follow the colour scheme; stroke 1.6 at the 24px viewBox, never thinner (a hairline light stroke vanished on a dark ground, 2026-11-07).
